# CRUD de Alunos e Turmas

## Descrição
Este projeto é um **CRUD (Create, Read, Update, Delete)** desenvolvido em Java para gerenciar o cadastro de **alunos** e **turmas**.  
Ele permite adicionar, editar, excluir e visualizar informações de alunos, além de associá-los a turmas, simulando um sistema acadêmico básico.

---

## Funcionalidades
- **Cadastro de alunos**: adicionar e editar informações como nome, matrícula e turma.  
- **Cadastro de turmas**: criar e atualizar turmas disponíveis.  
- **Consulta de dados**: listar todos os alunos e turmas cadastrados.  
- **Exclusão**: remover alunos ou turmas do sistema.  
- **Associação aluno-turma**: vincular alunos a turmas específicas.

---

## Tecnologias Utilizadas
- Linguagem: **Java**  
- IDE recomendada: **Eclipse** ou **IntelliJ IDEA**  
- Estrutura: Classes, listas e métodos para manipulação de dados
